# P6 Test cheap, kill rule first

**Rule.** Before building, write the guess and the number that kills it.

**Who did it**
- Cacioppo: 3 to 4 months of interviews, until she could predict about 75% of answers, before building. Verified.
- Butterfield: shut the game Glitch, kept the chat tool that became Slack. Verified.

**Research.** The strongest in the system.
- Camuffo et al. 2020: randomized trial, 116 startups. Founders taught to write testable guesses and kill thresholds pivoted more and earned more. Verified.
- Camuffo et al. 2024: 759 firms, four trials. Treated firms dropped bad ideas more often. Verified.
- Koning, Hasan, Chatterji 2022: A/B testing linked to better startup performance (35,918 firms; adoption not random).

**Breaks when.** Testing has no threshold and turns into drift. Pivots build from small decisions (Kirtley and O'Mahony 2023).

**For 4orm now.** Each Speer phase gets a written guess and a kill number before money moves. The mortgage calling plan already does this: learn on #76–100.

**Test.** Is the kill number written down before the spend?
